## License decision

The software uses **Apache License 2.0**, providing permissive reuse and an
explicit patent grant. No separate `NOTICE` file is currently needed because
the repository contains no identified third-party attribution notices.

The manuscript remains excluded from Git. Its current front matter states CC BY
4.0 for the article, but that notice must be verified against the
publisher-approved version and does not license the software automatically.
